## 🌟 核心功能特色與亮點

  - **地點**：台北南港展覽館 2 館 (TaiNEX 2)
  - **官網**：[https://taiwanindustryweek.com.tw/tw/exhibitor/refrigeration-hvac-taiwan](https://taiwanindustryweek.com.tw/tw/exhibitor/refrigeration-hvac-taiwan)
  - **主推解方**：工商業表後儲能（削峰填谷、契約容量優化防超約）、廠房屋頂隔熱光電（實測頂樓降溫 3~5°C，省下 8~12% 空調電費）、冷鏈不斷電微電網。

- **後續展會儲備**：2026 台灣國際智慧能源週、2026 高雄自動化展、2027 COMPUTEX。

---

### 2. 🎙️ 現場 AI 訪談速記 / 語音一鍵結構化解析入庫 (On-site AI Voice/Notes Capture)
針對展會現場**「業務手上拿滿名片、只有 30 秒能記下重點」**的極限場景：
- **🎙️ Web Speech API 語音直接辨識**：按下錄音鍵，對著手機直接口述（例：「剛才跟台灣極鮮冷鏈的林總聊過，他在大園有3,500坪冷凍庫，夏季電費每月200萬被罰超約，想了解表後儲能500kW削峰填谷，電話0918-369-258，下週二要出ROI，Jane跟進」）。
- **⚡ AI 智能實體解析器 (Smart Entity Extractor)**：
  - 秒級自動抽取：公司名稱、聯絡人、職稱、電話、Email、案場面積、電費規模、需求標籤（光電/儲能）、痛點摘要、指派業務、意向等級（🔥高意向）。
- **一鍵存入 CRM**：確認預覽後點擊「一鍵確認入庫」，直接寫入商機名冊並同步至 Supabase 雲端！全程僅需 10~15 秒！

---

### 3. ❄️ 冷凍空調展「1 分鐘現場快速訪談診斷卡」 (RHVAC Rapid Diagnostic Wizard)
- 業務與訪客對談時的「談話引導武器」：
  - **Q1. 設施類型**：低溫物流倉儲、食品加工冷凍庫、中央空調冰水主機、半導體無塵室、大型超市。
  - **Q2. 能源痛點**：夏季高尖峰電費暴增、壓縮機超約附加費、電壓瞬降跳機風險、頂樓高溫日曬、用電大戶條款。
  - **Q3. 規模級距**：契約容量 100~500kW / 500kW以上；每月電費 20~50萬 / 50~150萬 / 150萬以上。
- **即時生成進金生 6692 能效解方**：
  - 儲能容量建議（如 500kW/1,000kWh）
  - 屋頂光電隔熱效益（實測降溫 3~5°C）
  - 預估每年省下電費 NT$ 40~65 萬元！
- 提供 **「複製報告傳給客戶 (LINE)」** 與 **「一鍵儲存為商機」** 功能。

---

### 4. 📋 雙重保障 QR Code 現場行動問卷 ✕ 全螢幕立牌展示模式
- **修復白塊問題**：升級 CDNJS 高可用版本，並內建高解析度 API 動態備援，**100% 杜絕空白白塊**！
- **全螢幕立牌模式 (Kiosk Mode)**：點擊「全螢幕立牌」，將 iPad 或手機大螢幕直接立於攤位桌上，訪客可隨時自行掃碼。
- **30 秒極速行動問卷**：填答後自動關聯建立客戶商機，並寫入 Supabase 雲端問卷庫。

### 5. 🎯 客戶機會即時追蹤（下拉選單即時確認）
- **7 階段視覺化漏斗看板 (Pipeline Funnel)**：

  2. `需求確認` (Blue)
  3. `場勘/技術評估` (Purple)
  4. `方案報價` (Amber)
  5. `商務談判` (Orange)
  6. `贏單簽約` (Emerald - 勝利禮炮特效)
  7. `暫緩/戰略結案` (Rose)
- 每一列客戶配備直覺彩色下拉選單，點選立即生效、非同步寫入 Supabase 雲端！
